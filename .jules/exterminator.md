## 2026-07-30 - [Fix missing build before tests]\n**Discovery:** The initial `npm run test` command failed locally because the `dist/` folder was outdated or missing. Tests were trying to run against missing compiled JavaScript files.\n**Analysis:** The tests run against compiled `dist/` files, not the original `scripts/*.ts` files directly, so it's a hard requirement to have an up-to-date `dist/` directory to test properly.\n**Action:** Add `pretest: "npm run build"` to `package.json` scripts. This ensures that any `npm test` execution will automatically rebuild the `dist/` folder first.
