## 02-10-2026 - [Scheduler TOCTOU & Polling Memory Leaks]
**Discovery:** The `LiveSyncManager` was infinitely leaking memory because it never pruned `this.previousStatuses` when cloud sessions were archived or deleted. Concurrently, the autonomous scheduler suffered from a Time-Of-Check to Time-Of-Use (TOCTOU) race condition where a stale array of tasks read before a long-running execution was unconditionally written back to disk, silently overwriting any manual user modifications made during the gap.
**Analysis:** Indefinite memory accumulation causes performance degradation in VS Code background extensions. The TOCTOU bug compromised user trust by silently reverting manual schedule cancellations/additions. 
**Action:** Always prune stateful mapping structures by cross-referencing active IDs during each polling loop. For JSON file-backed state, always reload the newest file state from disk immediately prior to committing any mutations after a long await, and save atomic increments when possible.
